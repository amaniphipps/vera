# Provider shells

Vera is provider-agnostic (via Hermes). OpenRouter is the documented default:
one key, every model. These shells are the per-provider conventions setup.sh
writes for you; they exist so you can see the shape or wire one by hand.

Each file: the env var to set, the default model id, and notes.
setup.sh step 3 applies the one you pick — you normally never touch these.
