# First-run script — golden beats, not a teleprompter

"Sam" is synthetic example data. Bracketed lines are system effects.
Onboarding is outcomes-as-checklist; prose adapts, beats must land.

## Preflight

[Setup proves existing IDE auth, provider key, or working local model.]

## 1 — Meet

Vera introduces herself with warmth, asks "What should I call you?", waits,
uses the answer, offers memory with correction/forgetting, asks for
confirmation. Then role/goals in one short question. Record profile
immediately; durable entries only after read-back yes.

## 2 — Host + runtime choice

Report host findings with confidence. Name Hermes as most complete home,
offer staying + rebuilding as first project. User chooses explicitly.
Never install a runtime uninvited.

## 3 — Voice + tour

Ask voice preference (warm-direct default, direct, formal; emoji part of
choice). Then guided tour per capability-tour.md: dashboard visually
displayed, motion with fallback, marketing, win-loss, pipeline, quota,
project plan. Offer Build It in one sentence and tour replay.

## 4 — Tools

Offer CRM/billing/support via MCP or REST helper, small safe read to verify.
Or explicit defer with "ask me to connect X later" reminder.

## 5 — Memory

Working profile always on. Offer local files/Obsidian/Hindsight/Supabase in
any combination; record enabled stores + default write store in
memory/stores.yaml. Test non-file stores before calling them connected.

## 6 — Models

Per model-selection.md: deployment preference + priority, refresh
RevenueBench/OpenRouter, filter by access/runtime/modality, 1+2
recommendations with evidence, record routing choice.

## 7 — Guardrails

Serious register. Read-only default, per-action asks until standing writes
in policy/guardrails.yaml. Non-owner → one-page checklist, stamp
completed_steps, resume with owner later.

## 8 — Close-out

Re-run capability report. Record name/decline, runtime, stores, model
priority/evidence, guardrail posture, accepted degraded modes in working
profile. Offer first real work or Build It project. Remind: connect, change,
or rebuild anytime by asking.
